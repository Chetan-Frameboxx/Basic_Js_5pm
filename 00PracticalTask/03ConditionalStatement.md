**10 Practice Tasks – Conditional Statements (JavaScript)**
------------------------------------------------------------------------

### **Task 1:**

Check whether a number entered by the user is **even or odd**.

### **Task 2:**

Ask the user to enter a **month number (1–12)** and display the **number of days** in that month.

### **Task 3:**

Ask the user for **marks** and display the **grade**:

*   90–100 → A
    
*   75–89 → B
    
*   50–74 → C
    
*   Below 50 → Fail
    

### **Task 4:**

Check whether a given number is **positive, negative, or zero**.

### **Task 5:**

Ask the user to enter a **time (in 24-hour format)** and display:

*   0–11 → “Good Morning”
    
*   12–17 → “Good Afternoon”
    
*   18–23 → “Good Evening”
    

### **Task 6:**

Ask the user to enter a **month name** and display its **season**:

*   March–May → “Spring”
    
*   June–August → “Summer”
    
*   September–November → “Autumn”
    
*   December–February → “Winter”
    

### **Task 7:**

Check whether a **given year is a Leap Year** or not.

### **Task 8:**

Take three numbers and find the **largest** using if...else if...else.

### **Task 9:**

Ask the user to enter a **product price** and **membership status**.

*   If the user is a **member**, give 10% discount.
    
*   If not, show the full price.
    

### **Task 10:**

Take a **shopping amount** and apply discount using conditions:

*   Amount ≥ 5000 → 20% discount
    
*   Amount ≥ 2000 → 10% discount
    
*   Else → No discount
