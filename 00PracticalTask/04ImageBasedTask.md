 **JavaScript Conditional Tasks**
-----------------------------------

### **Task 1**

Check if the selected brand’s price is above ₹3000.If yes, display "Premium Brand", otherwise "Affordable Brand".

### **Task 2**

If the discount is greater than or equal to 15%, print "Good Offer".If it’s between 10–14%, print "Average Offer".Otherwise, print "Low Offer".

### **Task 3**

If the brand is "Nike" or "Puma", show "Sports Offer".If the brand is "Red Tape", show "Casual Offer".Otherwise, show "Fashion Offer".

### **Task 4**

If the price is above 5000 and the discount is below 10%, print "Too Expensive".Otherwise, print "Reasonable Deal".

### **Task 5**

If the brand is "Red Tape" and discount ≥ 20%, print "Best Buy".Else if brand is "Nike" and discount ≥ 10%, print "Good Buy".Otherwise, print "Wait for Sale".

### **Task 6**

Compare two brands and display which one is costlier and by how much.

### **Task 7**

Using switch, print brand rating based on the following:

*   Nike → 6
    
*   Puma → 7
    
*   Red Tape → 8
    
*   Adidas → 9
    

### **Task 8**

If after applying the discount, the price becomes less than ₹2500, print "Budget Pick",otherwise print "Premium Range".

### **Task 9**

If the brand is "Puma" and discount > 10%, or the price < ₹2000, print "Offer Valid".Otherwise, print "No Offer".

### **Task 10**

Ask the user for brand name and discount percentage using prompt() and print the appropriate message based on your conditions.
